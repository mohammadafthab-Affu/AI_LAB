## Summary:

# practical-2:

## Summary
This Python program is a Treasure Hunt path-finding project that demonstrates different search algorithms and path costs.
The rooms are represented as a graph, where each room is connected to other rooms.
BFS (Breadth-First Search) explores the nearest rooms first and searches level by level.
DFS (Depth-First Search) explores deeply along one path before going back and trying another path.
A door-cost system is used to calculate the total cost of travelling through different rooms.
The program compares different paths and finds the cheapest path based on the total door cost.
The program also changes some door costs to show that the cheapest path can change when the costs are modified.
Overall, the project demonstrates important concepts of graphs, BFS, DFS, functions, lists, dictionaries, loops, conditions, and path-cost calculation.

## Conclusion
The Treasure Hunt project shows how different search algorithms can be used to find a path from a starting room to a treasure. BFS searches broadly and checks nearby rooms first, while DFS goes deeper into one path before exploring other paths. The cost-based path calculation helps identify the most economical route instead of simply finding a route.
This project helps us understand that the best path can depend on the problem requirements. A path that reaches the treasure quickly may not always be the cheapest path. By changing the door costs, the program demonstrates how the optimal path can change. Overall, this project provides a simple and practical introduction to graph search and artificial intelligence path-finding techniques.

# practical-3:

## Summary
This program demonstrates the A* search algorithm using two examples: a grid path and an 8-puzzle. It compares a zero heuristic with smarter heuristics such as Manhattan distance and wrong-tile counting. The program finds shortest paths while showing how many states are explored.

## Conclusion
The project shows that A* can find the shortest solution efficiently. A good heuristic helps A* explore fewer boxes or puzzle arrangements while still finding the same shortest path. This makes A* useful for pathfinding, games, robots, and puzzle solving.

# practical-4:

## Summary
This program creates a Tic-Tac-Toe AI using the Minimax algorithm. The AI looks ahead at possible moves and chooses the best one. It also tests the AI against a random opponent and then improves the search using Alpha-Beta Pruning, which reduces unnecessary calculations.

## Conclusion
This project shows how AI can make intelligent decisions in games. Minimax helps the AI choose the best move, while Alpha-Beta Pruning makes the decision process faster and more efficient. The AI does not lose against the random opponent, demonstrating effective game-playing intelligence.
